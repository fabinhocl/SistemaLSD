Criar a página Administração.

Criar o painel Administração GED.

Criar cadastro de Setor.

Criar cadastro de Categoria.

Criar cadastro de TipoDocumento.

Criar cadastro de CampoMetadado.

Criar cadastro de PermissaoSetor.

Aplicar as permissões na lista e no detalhe de documentos.
